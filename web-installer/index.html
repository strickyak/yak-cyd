Lakatos OS — WebSerial Installer

Zero-install browser flasher for ESP32-2432S028R ("Cheap Yellow Display" / CYD)

Before You Begin

  1. Open this page in Google Chrome or Microsoft Edge on Windows, macOS, or Linux.
  2. Plug your CYD board into your computer with a data-capable USB cable.
  3. Click one of the install buttons below and select the USB serial port (typically USB Serial, CH340, CP2102, ttyUSB0, or cu.usbserial-*).

Option 1: Fresh Install (Lakatos OS + All 16 Built-in Apps) RECOMMENDED FOR NEW CYD

Flashes the bootloader, partition table, Lakatos OS firmware, and pre-loads the /flash LittleFS partition with all 16 compiled .lapp applications (Paint, NOAA Weather, Gallery, Conway's Life, Breakout, Space Invaders, Galaga, Defender, Tetris, Mandelbrot, Rubik's Cube, 15-Puzzle, Bouncing Ball, Ising Spin, Dendrite DLA, Pix-2).

Your browser does not support WebSerial. Please use Chrome or Edge. WebSerial requires HTTPS or localhost.

Option 2: Upgrade Lakatos OS Firmware Only KEEPS /flash CONFIG

Updates the Lakatos OS kernel at 0x10000 without touching your existing /flash filesystem, preserving your Wi-Fi configuration (/flash/config.ini) and files.

Option 3: Push / Refresh 16 .lapp Apps via Serial VFS

Already running Lakatos OS and want to push or update the 16 .lapp apps onto /flash or /sd without reflashing the OS or losing /flash/config.ini?

Uses Lakatos OS's built-in @FUSE serial RPC protocol at 115200 baud.
